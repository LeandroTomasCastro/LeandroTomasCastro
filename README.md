# ⚡ Proyecto destacado

## 🛒 SaikoPOS

**Sistema SaaS de gestión y punto de venta multiempresa desarrollado para Argentina.**

Estoy desarrollando SaikoPOS con una arquitectura pensada para que diferentes negocios puedan gestionar sus operaciones desde una misma plataforma de forma segura e independiente.

### 🧩 Algunas características

- 🛒 Punto de venta
- 📦 Gestión de productos
- 📊 Inventario y movimientos
- 💵 Gestión de cajas
- 🧾 Ventas y tickets
- 🔄 Devoluciones y cancelaciones
- 👥 Clientes
- 👤 Usuarios, roles y permisos
- 🔐 Seguridad multiempresa
- 📋 Auditoría
- 📈 Reportes y estadísticas
- 💰 Control de rentabilidad
- ☁️ Arquitectura SaaS
